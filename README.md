# 🐞 AI Bug Analyzer & Fix Advisor

## 📌 Project Overview

AI Bug Analyzer & Fix Advisor is an AI-powered application that helps developers analyze software bug reports using Retrieval-Augmented Generation (RAG). The system accepts bug reports as text or uploaded files, searches a historical defect knowledge base, and retrieves semantically similar bugs to assist developers in understanding recurring software issues.

This project is being developed as part of the Infosys Springboard Internship.

---

## ✨ Features

- Paste bug reports directly
- Upload bug reports, log files, or PDFs
- Historical Defect Knowledge Base
- Semantic Similarity Search
- RAG-based Retrieval
- ChromaDB Vector Database
- Streamlit Web Interface
